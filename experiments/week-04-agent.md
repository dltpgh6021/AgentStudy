# Week 04 — Gemini로 동작하는 Repository 분석 Agent

## 구현한 것

- 작업 기억(질문, 선택된 중간 분석, 누적 코드 관찰)을 가진다.
- LLM이 파일 읽기·검색 행동 후보를 생성한다.
- 각 후보의 실제 도구 관찰을 바탕으로 LLM이 평가한다.
- Python이 점수와 인용 유효성을 검사해 한 후보를 선택한다.
- 선택한 부모에서 다음 후보를 확장하고 최종 답변·탐색 트리를 저장한다.

## 확인한 것과 미확인 사항

- 현재 단위·통합 테스트: 총 11개 통과. 모델 응답은 모의 데이터이며 실제 모델 성능 측정이 아니다.
- 실제 연결: 사용자가 VS Code의 일반 터미널에서 gemini-3.5-flash-lite check 성공을 확인했다.
- 실제 diverse 실행: outputs/agent-diverse-01에서 completed, API 요청·응답 5회, 선택 경로 root → d1-c1 → d2-c1을 확인했다.
- 의미적 정확도: 큰 실행 흐름은 코드와 맞지만, 선택한 경로가 핵심 함수 본문까지 읽지 못한 한계가 있다. 아래 양식에 후속 비교와 검토 결과를 기록한다.
